## Возможности

- **Требования Telegram — автоматически**: видео и GIF превращаются в видеостикеры WebM (VP9), картинки — в статичные стикеры WebP; размер, частота кадров и объём файла подбираются сами, ничего настраивать не нужно
- **Максимум качества без превышения лимита**: битрейт и частота кадров рассчитываются по длительности и количеству движения, кодирование в два прохода; если файл больше 256 КБ, он перекодируется с меньшим битрейтом или частотой кадров, а слишком маленький — с большим битрейтом, чтобы «добрать» качество
- **Можно длиннее 3 секунд**: все кадры сохраняются, а длительность в заголовке файла переписывается на 2,99 с — так стикер проходит проверку длительности у бота @Stickers
- **Обрезка по времени и кадрирование**: ставьте метки на шкале времени и вырезайте из одного видео несколько фрагментов; рамка кадрирования поддерживает фиксацию пропорций, скруглённые углы, круг и зеркальное отражение; щелчок по фрагменту включает его зацикленный просмотр
- **Эмодзи и ключевые слова**: двойной щелчок задаёт эмодзи, через контекстное меню можно задать эмодзи и ключевые слова сразу для многих стикеров; можно подключить OpenAI-совместимую модель с поддержкой изображений, чтобы она сама подбирала эмодзи по настроению кадра
- **Много входных форматов**: MP4, MKV, WebM, MOV, AVI, FLV, GIF, APNG, анимированный WebP, PNG, JPG, WebP, BMP, TIFF, HEIC; прозрачность видео, GIF и PNG сохраняется
- **Пользовательские эмодзи**: переключитесь в режим 100×100 и сделайте целый набор Custom Emoji за один раз
- **Интерфейс на русском, английском и упрощённом китайском**: по умолчанию выбирается язык системы, сменить его можно в меню ⚙ в правом верхнем углу
- **Светлая и тёмная темы**: по умолчанию как в системе, либо выберите светлую или тёмную в меню ⚙; смена применяется сразу
- **Ничего не потеряется**: список и все правки сохраняются автоматически и восстанавливаются при следующем запуске; можно также экспортировать исходники с файлом параметров и продолжить на другом компьютере

## Быстрый старт

1. **Перетащите** видео, GIF или картинки **в окно** или нажмите «Добавить файлы» / «Добавить папку»
2. Чтобы вырезать фрагменты или кадрировать изображение, нажмите ✂️ в строке — откроется редактор
3. **Дважды щёлкните по столбцу «Имя файла»**, чтобы задать эмодзи; в контекстном меню можно задать эмодзи и ключевые слова сразу для нескольких строк или поручить подбор эмодзи ИИ
4. Нажмите «🚀 Начать конвертацию». После завершения в папке вывода появится `TG_Stickers_<дата>_<время>.zip` (стикеры и файл `stickers.json` с их эмодзи и ключевыми словами)

### Обрезка и кадрирование

Одно видео можно разрезать на несколько фрагментов, у каждого свои начало и конец, рамка кадрирования, скругление углов, отражение и эмодзи. Щелчок по карточке фрагмента или его блоку на шкале времени зацикливает воспроизведение внутри фрагмента; `[` / `]` ставят начало и конец, `Пробел` — воспроизведение и пауза.

## Требования Telegram к стикерам

Программа автоматически выводит файлы по официальным требованиям:

| Тип | Размер | Формат | Макс. объём |
|---|---|---|---|
| Видеостикер | 512 px по длинной стороне | WebM (VP9), без звука, ≤ 3 с | 256 КБ |
| Статичный стикер | 512 px по длинной стороне | WebP, с прозрачностью | 512 КБ |
| Пользовательский эмодзи | 100×100 | видео WebM / статичный WebP | 64 КБ |

## Частые вопросы

<details>
<summary><b>При запуске Windows пишет «Система Windows защитила ваш компьютер»</b></summary>

У программы нет платного сертификата подписи кода, поэтому Windows SmartScreen показывает «неизвестный издатель». Нажмите «Подробнее» → «Выполнить в любом случае». В описании каждого релиза указаны контрольные суммы SHA-256, по ним можно проверить скачанный файл.
</details>

<details>
<summary><b>Как пользоваться подбором эмодзи через ИИ</b></summary>

Нажмите «⚙️ Настройки ИИ» на панели инструментов и укажите API-ключ, Base URL и название модели. Подойдёт любая модель с поддержкой изображений, совместимая с форматом OpenAI Chat Completions (OpenAI, DeepSeek, Moonshot, прокси вроде OneAPI и т. п.). Если Base URL указывает на ваш компьютер (localhost / 127.0.0.1), ключ можно не заполнять. Модель видит только итоговую область стикера (с кадрированием, скруглением и отражением); для видео несколько кадров склеиваются в одно изображение.
</details>

<details>
<summary><b>Конвертация не удалась или файл превышает лимит</b></summary>

Длинные фрагменты со сложной картинкой и быстрым движением могут не уложиться в 256 КБ даже при минимальной частоте кадров. Сократите фрагмент или обрежьте лишнее по краям. Если в «Пресет кодирования» выбран «⚡ Быстрый экспорт», верните стандартный «✨ Высокое качество» — два прохода и лёгкое шумоподавление дают лучшее качество при том же объёме. Причина ошибки выводится в строке состояния и в журнале.
</details>

<details>
<summary><b>Где хранятся настройки и кэш</b></summary>

По умолчанию в `%LOCALAPPDATA%\TelegramStickerMaker` (настройки, автосохранённый список, кэш предпросмотра). Папку можно перенести на другой диск через «Папка данных» справа, а «Очистить кэш» освобождает место. При удалении программы эти данные сохраняются, так что после переустановки можно продолжить работу.
</details>
